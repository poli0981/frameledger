# Every member of a vendor's struct that the Overlay reads for Advanced metrics - the whole of what a hooked game's
# arguments give up beyond the frame record (docs/18_GPU_VENDOR_APIS.md section Train B; owner decisions D111, D115 and
# D116, 2026-11-11).
#
# tools/overlay-fields-check.ps1 holds src/native/FrameLedger.Overlay/include/fl_adv_fields.h to this list in both
# directions, on every build: a member read there that is not here is red, and a name here that the header no longer
# reads is red. A camera's position, axes or matrices are red even when they are listed - so one cannot be let in by
# adding a line to this file.
#
# One `Struct::member` per line. To add a read: find the release of the vendor's SDK that introduced the member and add
# it to the table in docs/17_HOOK_ENGINE.md section "Which struct version carries which field" (D115) - a member is read
# only at a struct version proven to carry it - then add its name here, and say in the pull request what it tells and
# why it is an argument of a call the Overlay hooks (rule 4).
