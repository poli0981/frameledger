# Every NVAPI entry point FrameLedger.NvapiBridge calls - the whole of what a shipped FrameLedger binary asks the NVIDIA
# driver (docs/18_GPU_VENDOR_APIS.md section Runtime policy; owner decision D108, 2026-11-11).
#
# tools/nvapi-readonly-check.ps1 holds src/native/FrameLedger.NvapiBridge/src/fl_nvapi_bridge.cpp to this list in both
# directions, on every build: a call that is not here is red, and a name here that the bridge no longer calls is red.
# A name that sets, saves, restores, registers or controls something is red even when it is listed, and so is one that
# returns an identifier (D104) - so a writer cannot be let in by adding a line to this file.
#
# One name per line. To add a read: read what the entry point does in the vendored nvapi.h, add its name here, and say
# in the pull request what it reads and why that is not an identifier.
