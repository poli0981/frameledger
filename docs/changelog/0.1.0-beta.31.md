## [0.1.0-beta.31] - 2026-10-26

**The thirty-first pre-release: the remaining library updates.** The same unsigned installer: verify its hash against
`SHA256SUMS.txt`, then *More info → Run anyway*.

**Updating from `0.1.0-beta.30`:** Help ▸ Check for updates, then *Restart to update* with no game running. Nothing is
shown for you to accept again (the Disclaimer stays 2.11, the Privacy Policy 2.12), the ledger stays at schema 21, and
no game is read again: the detection rules (`2026.10.4`) are beta.30's. This is the first update that beta.30's updater
(Velopack 1.2.161) installs; if it downloads the whole package rather than a few megabytes, or the App does not come back,
the installer on this page puts it right. What you see and what is recorded are beta.30's; the libraries under them are
newer.
