# FrameLedger user guide

FrameLedger records how your games run on this PC — frame rate, frame times, the settings a game is really rendering
with, temperatures, and how much memory the game uses — and keeps every session so you can compare them later.
Everything stays on your PC.

Each page below takes a minute or two to read. The first six are the guide; the next four are there to look things up.

What FrameLedger cannot do is listed on its own page: [Limitations](../LIMITATIONS.md) (in the app: Help ▸
Limitations).

**FrameLedger is beta software.** It certainly still has bugs. If something goes wrong, Help ▸ Report a bug… builds a
report on your PC that you can look at before you decide to share it.

This guide is part of FrameLedger and describes the version it came with. It is also in the project's repository on
GitHub, in the `guide` folder, and on the project's wiki, which shows the newest release.
